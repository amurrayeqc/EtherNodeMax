# EtherNodeMax

EtherNodeMax implements a distributed-edge architecture for high-performance, multi-threaded processing and event-driven management of decentralized node interactions.

With EtherNodeMax, you get a lightweight tool that stays out of your way.

**What you get**

- EtherNodeMax implements a distributed-edge architecture
- for high-performance, multi-threaded processing and
- event-driven management of decentralized node

## Technology Stack

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/EtherNodeMax.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
